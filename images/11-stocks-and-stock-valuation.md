# Image briefs — Chapter 11: Stocks

## Figure 11.1 — Three families of valuation

**Where:** Concept 2 opening.

**Subject.** Three columns: DDM, DCF, Multiples. Each with a one-line "what it is" + "when to use" + "key formula" + "main limitation."

**Caption.** *Three families, each answering "what is this stock worth?" by a different route. None is right by itself.*

---

## Figure 11.2 — Gordon model sensitivity

**Where:** Concept 2, after the DDM section.

**Subject.** A 2D heatmap showing implied stock value as a function of growth rate $g$ (x-axis: 2-7%) and required return $r$ (y-axis: 7-12%). Cell colors range from red (low value) to green (high value).

**Caption.** *A 1-percentage-point change in either input swings valuation 20-35%. This is why DDM should never be reported as a single number.*

---

## Figure 11.3 — DCF terminal value dominance

**Where:** Concept 2, in the DCF section.

**Subject.** Stacked bar chart for a representative DCF: explicit-period FCF contributions (years 1-5) shown as smaller stack; terminal value as the dominant block. Shows that 60-80% of value is typically in the terminal piece.

**Caption.** *Terminal value typically dominates DCF. The forecast period gets the analytical attention; the terminal value provides the answer.*

---

## Figure 11.4 — Triangulation across methods

**Where:** Concept 2, in the worked example.

**Subject.** A horizontal range chart showing the implied value per share from DDM ($88), DCF ($94), P/E ($92), EV/EBITDA ($98). Current market price marked. "Fair value range" highlighted as $88-98.

**Caption.** *Four methods, four different numbers. Triangulation produces a defensible range, not a single point.*
